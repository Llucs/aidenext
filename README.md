## Features

- [x] Gradle support.
- [x] `JDK 17` and `JDK 21` available for use.
- [x] Terminal with necessary packages.
- [x] Custom environment variables (for Build & Terminal).
- [x] SDK Manager (Available via terminal).
- [x] API information for classes and their members (since, removed, deprecated).
- [x] Log reader (shows your app's logs in real-time)
- [ ] Language servers
    - [x] Java
    - [x] XML
    - [ ] Kotlin
- [ ] UI Designer
    - [x] Layout inflater
    - [x] Resolve resource references
    - [x] Auto-complete resource values when user edits attributes using the attribute editor
    - [x] Drag & Drop
    - [x] Visual attribute editor
    - [x] Android Widgets
- [ ] String Translator
- [ ] Asset Studio (Drawable & Icon Maker)
- [x] Git

## Installation

Download the AIDE Next APK from the [Releases](https://github.com/Llucs/aidenext/releases) page.

> _Please install AIDE Next from trusted sources only._

## Limitations

- For working with projects in AIDE Next, your project must use Android Gradle Plugin v8.0.0 or newer. Projects with older AGP must be migrated to newer versions.
- No official NDK support.

The app is still being developed actively. It's in beta stage and may not be stable. If you have any issues using the app, please let us know.
